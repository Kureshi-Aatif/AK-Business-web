Launching a new business website is an exciting milestone. However, rushing to deploy without systematic testing often leads to broken contact forms, missing SEO tags, slow load times, and lost sales opportunities on day one.

Whether you are building your website yourself or working with an agency, following a rigorous **website checklist before launch** ensures that your digital storefront is flawless, secure, and ready to rank on search engines.

Here is the exact 25-point checklist we run before taking any client website live at AK Digital Studio.

---

## Phase 1: On-Page & Technical SEO
- [ ] **1. Unique Title Tags**: Every page has a descriptive title tag (50–60 characters) with the primary keyword and brand name.
- [ ] **2. Compelling Meta Descriptions**: Every page has a click-focused meta description (140–160 characters) with a clear call-to-action.
- [ ] **3. Heading Hierarchy**: Exactly one `<h1>` per page, followed by logical `<h2>` and `<h3>` tags with no skipped levels.
- [ ] **4. Image Alt Text**: All images have descriptive alt attributes for accessibility and Google Image search indexing.
- [ ] **5. Canonical Tags**: Every indexed URL specifies a self-referencing canonical tag to prevent duplicate content penalties.
- [ ] **6. Dynamic XML Sitemap**: A clean `/sitemap.xml` is present, listing only 200 OK public pages.
- [ ] **7. Robots.txt Configuration**: Disallows `/admin` and private backend endpoints while pointing search bots to the sitemap.
- [ ] **8. Structured Data (JSON-LD)**: Schema markup for `LocalBusiness`, `Organization`, and `Service` is implemented and validated.

---

## Phase 2: Design, Usability & Cross-Device Testing
- [ ] **9. Mobile Responsiveness**: Tested at 375px (mobile), 768px (tablet), and 1280px+ (desktop) with zero horizontal scrolling.
- [ ] **10. Touch Target Sizes**: All buttons and navigation links are at least 44x44px for easy tapping on mobile screens.
- [ ] **11. Contrast & Readability**: Text contrast meets WCAG AA standards (minimum 4.5:1 ratio against background colors).
- [ ] **12. Visible Focus States**: Keyboard navigation functions smoothly with visible focus rings on all interactive elements.
- [ ] **13. Custom 404 & 500 Pages**: Helpful, branded error pages that guide visitors back to the home or contact page.

---

## Phase 3: Forms, Security & Lead Capture
- [ ] **14. End-to-End Form Testing**: All quote and contact forms submit properly and save cleanly to the database.
- [ ] **15. Auto-Reply & Admin Emails**: Notification emails trigger reliably with reference IDs and customer contact info.
- [ ] **16. WhatsApp Click-to-Chat**: Floating WhatsApp buttons and product inquiry buttons open properly with pre-filled messages.
- [ ] **17. Anti-Spam Protections**: Hidden honeypot fields and rate limiters protect forms without frustrating real users.
- [ ] **18. SSL / HTTPS Enforcement**: All HTTP traffic redirects permanently (301) to HTTPS with active HSTS headers.
- [ ] **19. Security Headers**: Strict CSP, X-Frame-Options, and X-Content-Type-Options headers active via Helmet.

---

## Phase 4: Performance, Analytics & Compliance
- [ ] **20. Sub-2.5s LCP**: Core Web Vitals optimized with compressed images, critical CSS, and deferred scripts.
- [ ] **21. Google Analytics 4**: GA4 measurement tag configured to record key conversions (`inquiry_submit`, `whatsapp_click`).
- [ ] **22. Google Search Console**: Domain property verified and sitemap submitted.
- [ ] **23. Cookie Consent Banner**: Compliant with data privacy guidelines, loading analytics only after user consent.
- [ ] **24. Privacy Policy & Terms**: Clear policies covering data retention, contact methods, and DPDP compliance.
- [ ] **25. Automated Backups**: Scheduled database backups established with retention policies.
