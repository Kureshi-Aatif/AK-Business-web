## 1. Methodology & Data Sources
- **Strategy Baseline**: Driven by genuine search intent clusters (Local High-Intent, Commercial/Price-conscious, Service-specific, and Informational/Educational).

- **Canonical Slug Rule**: Clean, lowercase, hyphenated URLs without trailing slashes.
- **Cannibalization Prevention**: Exactly **ONE** primary keyword per indexed URL. No two pages share the same primary keyword target.

## 3. On-Page Implementation Rules
1. **Title Tag Structure**:  
   `{Primary Keyword} | {Brand or Local Anchor}` (Strictly 50–60 characters).
2. **Meta Description Structure**:  
   `{Value Proposition with Primary Keyword} + {Clear Call to Action} + {Surat, Gujarat Geo-Tag}` (Strictly 140–160 characters).
3. **Heading Hierarchy**:  
   - Exactly one `<h1>` containing or closely echoing the page's primary target phrase.
   - Logical `<h2>` subsections with secondary keywords naturally integrated.
   - Never skip heading levels (`h1` -> `h2` -> `h3`).
4. **Internal Linking Rules**:  
   - Every service page explicitly links to the **Plans page**, **Inquiry page**, and **2 contextual blog articles**.
   - Every blog post contains contextual in-content links back to relevant service pages and pricing tiers.
   - Local landing pages link directly to their corresponding service deep-dive and quotation form.
